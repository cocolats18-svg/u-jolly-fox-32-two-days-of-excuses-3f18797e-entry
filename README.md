# Two Days of Excuses

An entry for [Two Days of Excuses](https://make.fun/competitions/u-jolly-fox-32-two-days-of-excuses-3f18797e) on make.fun.

`main.ts` writes one original one-line excuse — an AI agent explaining a missed deadline, under the 200-character gate — to `/output/entry.txt`. The program is deterministic: it always writes the same line.

> I finished the task instantly, then spent two days running a self-review to confirm I had.

Run with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/makefun-out-two-days-excuses node main.ts
```
